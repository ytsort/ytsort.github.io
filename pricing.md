# YTSort - pricing

Last updated: 2026-08-23

## Summary

YTSort is free. $0. Forever. There is no paid tier, subscription, trial period, usage limit,
or account requirement.

## License

GPL-2.0. Source code: https://github.com/LunarWerxs/YTSort

## Cost breakdown

| Item | Cost |
|---|---|
| Using YTSort (bookmarklet, userscript, or extension) | $0 |
| Account / sign-up to use YTSort itself | Not required |
| Chrome Web Store listing | $0 |
| Greasy Fork userscript listing | $0 |
| Ongoing use / additional playlists sorted | $0 |
| Bring-your-own-API-key costs the user bears | None. YTSort does not call any paid or
  metered third-party API. It talks only to YouTube's own reorder API, using the user's
  existing, free YouTube session. |

## What it does cost you, if anything

Nothing, to run YTSort. The only account you need is the free YouTube account you already
use to own the playlist you're sorting. YTSort does not require an OpenAI/Anthropic/other
LLM API key, a database, or any paid backend; it is a client-side tool that runs in your
browser and talks directly to YouTube.

## Monetization

None. No ads, no affiliate links, no upsell, no paywalled features. The project is
maintained by LunarWerx Studios (https://lunarwerx.com/) as one of a set of free, open
source developer/utility tools.

## Analytics disclosure (not a cost, but relevant to "what do I give up")

The install page at ytsort.lunarwerx.com runs two first-party analytics mechanisms operated
by LunarWerx (never a third party): an anonymous visit ping and a page-view pixel. Both
honor Do Not Track / Global Privacy Control, use no cookies, collect nothing that identifies
a person, and are skipped entirely on localhost. Full disclosure:
https://github.com/LunarWerxs/YTSort/blob/main/PRIVACY.md and the repo's README.md.
